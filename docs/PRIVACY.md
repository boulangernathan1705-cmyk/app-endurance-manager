# Confidentialité

La politique utilisateur publiée par le site se trouve dans `privacy.html`.

Lorsqu'une fonctionnalité modifie les données personnelles traitées, les cookies, les durées de conservation ou les prestataires externes, mettre à jour cette page dans la même pull request.

État au 10 septembre 2026 :

- Discord OAuth utilise uniquement le scope `identify` ;
- le site conserve l'identifiant Discord et le nom d'affichage, pas l'adresse e-mail Discord ;
- session : 7 jours maximum ;
- accès invité : cookie jusqu'à 365 jours ;
- état OAuth : environ 10 minutes ;
- clés anti-abus basées sur une empreinte hachée et une fenêtre de 10 minutes ;
- aucun cookie publicitaire ou d'analyse d'audience n'est ajouté par le code de l'application.
