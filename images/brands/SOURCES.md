# Logos de marques

Logos des constructeurs, utilisés seulement pour nommer la voiture d'un équipage. Ils restent la propriété des marques.

- La plupart : dépôt `filippofilip95/car-logos-dataset` (recadrés sur l'emblème, logos sombres éclaircis pour le fond sombre).
- Peugeot, Renault, Cadillac, Chevrolet : Simple Icons (CC0), versions actuelles.
- Oreca, Duqueine, Glickenhaus, Vanwall : Wikipedia. Dallara : site officiel.
- Sans logo : Adess, Isotta Fraschini (deux lettres, voir `shared/car-brands.mjs`).

Format : `.webp`, 112 × 64 px au plus, fond transparent.
